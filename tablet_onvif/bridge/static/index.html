For standalone Docker, enter the admin token stored in the data directory. Home Assistant ingress signs you in automatically.

Connection

The default HA URL uses the Supervisor connection. Docker installs use HA_URL and HA_TOKEN. Use the host’s LAN IPv4 as the discovery interface if multicast uses the wrong network.
